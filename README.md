# UE5 Modular Fuel Simulation System (SG 0.1 & 0.2)

Sistema modular y desacoplado de interacción y simulación de combustible desarrollado en **Unreal Engine 5**. Diseñado enfocándose en arquitectura limpia, escalabilidad y separación de responsabilidades lógicas mediante el uso de Eventos Personalizados (CE) y Funciones (FN).

## Aspectos Técnicos y Arquitectura

- **Desacoplamiento Lógico:** Separación de la lógica de procesamiento (Funciones) frente a la ejecución y flujo de eventos (Custom Events).
- **Flujo de Gameplay:** Gestión de estados del vehículo, simulación de repostaje, consumo progresivo e interfaz de usuario reactiva.
- **Optimización de Assets:** Colisiones dedicadas y estados integrados para surtidor, vehículo y bidones.
